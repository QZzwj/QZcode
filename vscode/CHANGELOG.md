# Changelog

版本号跟安装包一致；每一版都在 `vsix-history/` 里留了 vsix，随时能装回旧版。

## 3.6.x

- **3.6.0** **不再需要机器上装 Node**：本地服务改用 VS Code 自带的运行时（Electron + `ELECTRON_RUN_AS_NODE=1`）启动，装好即用。`qzcode.nodePath` 默认留空 = 用自带运行时，填了才用外部 node。体检里也会标出"来自 VS Code 自带运行时"。

## 3.5.x

- **3.5.3** 扩展面板描述改成和新 README 一致的定位（四角色接力 / 自带后端）；A 的系统提示词不再自称「三模型流水线」；清掉状态栏里指向已删除工作台的提示。
- **3.5.2** 重写 README（对齐 3.5 现状：四角色、侧栏唯一界面、15 条命令、8 个设置项、运行记录/回滚/git/计划模式/@文件/预算/视觉模型）；新增 `QZcode: 打开运行记录` 命令。
- **3.5.1** 空状态顶部加 `QZcode` 品牌行（QZ 加粗）。
- **3.5.0** 一批功能：计划模式（先出任务书再执行）、多轮上下文、运行记录入口、停止后可回滚、按文件回滚、预算硬闸、运行中切工作区拦截、`@文件` 引用。

## 3.4.x

- **3.4.2** 「✔ 通过 / ✘ 未通过」单独一行居中显示。
- **3.4.1** 工作区不是 git 仓库时先 `git init` 再提交（自动提交开关不再隐藏）。
- **3.4.0** 断线真正可恢复：`since` 续传 + 退避重连 + 404 快速结论 + 「重新发送 / 重启后端」。

## 3.3.x

- **3.3.3** 后端 stderr 落盘 `backend.log`，退出时把报错末尾写进 `activate.log`。
- **3.3.2** ENOENT 加固：`killTree` 接住 spawn 错误、异常写完整堆栈、路径不存在给中文提示。
- **3.3.1** 发出消息后到首个回复之前显示「正在思考中」。
- **3.3.0** 每轮写 `.qzcode/runN.md`（L/A/B/C 各自干了什么）。

## 3.2.x

- **3.2.3** 修视觉设置保存卡死（消息处理器挂错了面板）。
- **3.2.2** 修成本页空白（`listRoles` 少返回 catalog、`reloadCost` 可能挂住）。
- **3.2.1 / 3.2.0** 侧栏重做（Codex/DeepSeek 风格：角色色、徽章、工具行、diff、居中空状态）。

## 3.0.x – 2.x

- 侧栏聊天取代 web GUI / 三栏工作台；L 定位为主控（派活、盯进度、打回返工）。
- 停止改为硬中断（95ms 内真的停下）；每步速度统计只算输出 token 与模型时间。
